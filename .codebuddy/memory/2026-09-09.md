### 经验：网页端数据同步流程
1. 改 `data/shortcuts/*.json` + `data/apps.json`
2. `npm run gen:pinyin`
3. `npx tsx web/scripts/build-data.ts`（关键！把根 data 同步到 web/public/data，生成 all.json/apps.json/search.json/各 app 文件）
4. 在 `web/` 下 `npm run build`（tsc + vite + 静态页 + sitemap）
5. `npx wrangler pages deploy dist --project-name keyatlas --branch=main --commit-dirty=true`

## UI 改动（commit `7c92ad6`）

### 1. 扩展：设置侧边栏去掉动画（用户明确要求"纯打开，不要弹一下"）
- `css/style.css`：删掉 `.settings-panel` 的 `transform: translateX(100%)` + `transition`；
  `.settings-backdrop` 的 `opacity: 0` + `transition` 改为 `opacity: 1`。
- `js/app.js` `closeSettings()`：去掉 `setTimeout(..., 220)`，改为同步 `hidden = true`
  （否则无动画后关闭仍会卡 220ms）。
- 现在点设置按钮 → 侧边栏**瞬时出现**；关闭也是瞬时。

### 2. 网页版：深色模式
**关键前提**：`web/src/index.css` 早就写好了完整的 `[data-theme="dark"]` 变量块（43–60 行），
但 JS 侧从未接入 —— 所以只需要"接线"，不用重写配色。
- 新增 `web/src/theme.ts`：`ThemeMode = light | dark | system`，localStorage key `keyatlas-theme`，
  默认 `system`；`applyThemeMode()` 给 `<html>` 设 `data-theme`；`useThemeState()` hook 并监听
  `prefers-color-scheme` 实时跟随系统。
- `web/index.html`：`<head>` 加内联脚本，在样式生效前定好 `data-theme`（防深色模式白屏闪烁）。
- `web/src/components/Header.tsx`：右侧新增三态主题按钮
  （🖥️跟随系统 → ☀️浅色 → 🌙深色 循环）；语言按钮一并改用 `.theme-toggle` 纯 CSS 类，
  移除原来的 JS inline hover（遵守"hover 用纯 CSS"规则）。
- `index.css`：新增 `.theme-toggle` 样式（纯 CSS `:hover`/`:focus-visible`）；
  深色下覆盖两处硬编码：① `body` 顶部白色渐变（原 `rgba(255,255,255,.72)` 会让深色顶部发白）
  ② `.favorite-btn` 激活态浅黄底 `#fff7e6`。
- i18n 里本就有 `themeLabel/themeLight/themeDark/themeSystem` 中英文案，直接复用，无需新增。
