## KeyAtlas 谷歌扩展搭建（从 PRD 从零构建）
- 按 `KeyAtlas_MVP_PRD.md` 搭建了完整 Manifest V3 Chrome 扩展（快捷键搜索引擎）。
- 技术栈：Vanilla JS + HTML/CSS，无后端无登录，JSON 驱动数据。
- 目录结构：
  - `manifest.json`（MV3，去掉了 default_locale 避免强制 _locales）
  - `popup.html` + `css/style.css`（现代简约、圆角卡片、软阴影、深/浅主题、宽 380px）
  - `js/i18n.js`（双语 zh/en，语言优先级 URL ?lang= > localStorage > navigator.language）
  - `js/storage.js`（chrome.storage.local + localStorage 回退，收藏/最近50/主题）
  - `js/data.js`（加载并索引所有 JSON）
  - `js/search.js`（加权模糊搜索，name/desc/keywords/appName/keys 双语）
  - `js/app.js`（四 Tab：搜索/分类/收藏/最近，OS 自动检测，点击卡片复制按键）
  - `data/categories.json` `data/apps.json` + `data/shortcuts/*.json`（16 个应用/系统）
- 功能：搜索、分类下钻(分类→应用chip)、收藏、最近、OS 切换、语言切换全区域刷新、深浅主题、点击复制。
