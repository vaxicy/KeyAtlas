## 修复：设置面板关不掉 + 全站自定义滚动条（commit `22e5d91`）

### ⚠️ 重要教训：`display:flex` 会覆盖 UA 的 `[hidden]` 规则
- 上一轮删掉 `.settings-panel` 的 `transform: translateX(100%)` 后，面板失去了"移出屏幕"式隐藏；
  它的 `display: flex` 优先级高于浏览器默认的 `[hidden] { display: none }`，
  导致 `el.hidden = true` 完全无效 → **面板永远关不掉**。
- **修复**：`css/style.css` 加全局 `[hidden] { display: none !important; }`。
- **今后规则**：任何元素若 CSS 里显式设置了 `display`，靠 `hidden` 属性控制显隐时，
  必须确认有 `[hidden]{display:none}` 兜底；删 transform/opacity 类"视觉隐藏"前，
  先确认 JS 的显隐机制依赖哪一层。

### 滚动条按全局规则改造（scrollbar-no-native RULE）
**扩展端**（3 个有界型容器：`.content` / `.settings-body` / `.detail-drawer-panel`）：
- CSS：全局 `*::-webkit-scrollbar-button{display:none}` + 每容器
  `scrollbar-width:none` + `::-webkit-scrollbar` 全家桶（button/track/thumb/corner）压 0。
- 新增 `js/scrollbar.js`：零依赖 JS 轨道+滑块（`.ka-scrollbar-track/.ka-scrollbar-thumb`），
  thumb 高度 clamp 45%~60%（min 30px），支持拖拽、轨道点击翻页、
  scroll/resize/ResizeObserver/MutationObserver(rAF 防抖) 刷新；
  attach 时若容器 position 为 static 自动补 relative。
- `popup.html` 在 `app.js` 后引入 `scrollbar.js`；
  `app.js` 的 openSettings/openDetailDrawer 的 rAF 里调 `KeyAtlasScrollbars.updateAll()`。

**网页端**（viewport 型页面滚动）：
- `index.css`：`*{scrollbar-width:none}` + `*::-webkit-scrollbar` 全家桶全站隐藏原生条；
  新增 `.ka-scrollbar-track-page`（fixed）+ thumb 样式（用 `--border-color`/`--sub-color` 适配深浅主题）。
- 新增 `web/src/scrollbar.ts`（viewport 型：`window.scrollY/scrollTo/innerHeight/scrollHeight`），
  `main.tsx` 引入；MO observe document.body 捕捉 SPA 路由切换。
