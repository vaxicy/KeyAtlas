## 网页版搜索修复 + 搜索联想/推荐（web/）
问题：搜索无结果/白屏。三层根因 + 修复：
1. **pinyin 类型不匹配**：数据里 `pinyin` 是**空格分隔字符串**（如 `"yi dong gong ju ..."`），但 `types.ts` 定义为 `string[]`，`search.ts` 用 `...(s.pinyin||[])` 展开成单字符导致匹配异常。
   - 修：`types.ts` 改 `pinyin?: string | string[]`；`search.ts` 新增 `pinyinTokens()` 归一化，字段拼接加 `?.` 空值保护。
2. **数据加载不健壮**：`all.json` 3.7MB，fetch 可能超时/截断；localStorage 缓存损坏后永久命中坏数据。
   - 修：`data.ts` 加 `DATA_VERSION='v2'` 版本化缓存键、`isValidData()` 校验（apps/shortcuts 非空）、`clearStaleCaches()` 清旧版本、fetch 15s 超时(AbortController)+重试1次、inflight 去重并发。
3. **搜索无联想/无推荐**：
   - `search.ts` 新增 `suggest(query,data,limit)` → app+shortcut 联想。
   - `SearchBar.tsx` 重写为受控组件：实时联想下拉（180ms 防抖、↑↓/Enter/Esc 键盘导航、点外部关闭、app 显示「应用」徽章）。
   - `SearchPage.tsx` 重写：q 直接从 URL searchParams 取（不再 useState 导致导航不刷新）、useMemo 计算结果、空查询/无结果时显示「热门搜索」chips + 「推荐应用」卡片。
   - `i18n.ts` 加 hotSearches/recommendedApps/resultsFor 键；`AppCard.tsx` 应用名跟随语言（zh 优先）。
数据本身正常：153 apps / 6192 shortcuts / figma 68 条。已 build + `wrangler pages deploy` 部署到 master.keyatlas.pages.dev。
