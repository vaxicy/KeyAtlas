KeyAtlas 隐私权政策

Privacy Policy · 最后更新 2026-07-15

数据收集 / Data Collection

KeyAtlas 不收集、不传输、不存储任何用户个人数据。

KeyAtlas does not collect, transmit, or store any personal user data.

权限使用 / Permission Usage

扩展仅使用 chrome.storage.local 保存用户的语言偏好设置（中文 / 英文切换），以便记住上次选择。该数据仅存储在用户本地浏览器中，不会上传到任何服务器。

The extension only uses chrome.storage.local to save the user's language preference (Chinese / English toggle). This data is stored locally in the user's browser and is never uploaded to any server.

网络访问 / Network Access

KeyAtlas 完全离线运行。所有快捷键数据均内置在扩展包中，扩展不会发起任何网络请求，也不会加载任何远程代码。

KeyAtlas runs entirely offline. All shortcut data is bundled within the extension package. The extension makes no network requests and loads no remote code.
