### 经验：网页端数据同步流程
1. 改 `data/shortcuts/*.json` + `data/apps.json`
2. `npm run gen:pinyin`
3. `npx tsx web/scripts/build-data.ts`（关键！把根 data 同步到 web/public/data，生成 all.json/apps.json/search.json/各 app 文件）
4. 在 `web/` 下 `npm run build`（tsc + vite + 静态页 + sitemap）
5. `npx wrangler pages deploy dist --project-name keyatlas --branch=main --commit-dirty=true`
